## 🚀 Getting Started

### Prerequisites

No special tools required — just a modern web browser.

### Running Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/abhimani-konara/portfolio-website.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd portfolio-website
   ```

3. **Open `index.html` in your browser**
   ```bash
   # On macOS
   open index.html

   # On Windows
   start index.html

   # Or simply drag and drop index.html into your browser
   ```
